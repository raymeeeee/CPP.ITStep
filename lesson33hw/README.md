# lesson33hw

В цій програмі знаходиться віртуальний клас Publication та похідні від нього Book та Magazine, також є клас-контейнер Library що містить вектор Publication*.
Віртуальний клас Exception відповідає за похідні від нього BookException(помилка порожній рядок) та YearException(помилка нульовий або від'ємний рік).
